How the System Works

Edge-AI intrusion detection workflow

The ESP32 acts as the central simulated IoT gateway for the Wokwi environment.

The LED represents the Smart Light. The DHT22 represents the Smart Thermostat. The PIR sensor represents the Smart Camera. The Servo represents the Smart Lock. The potentiometer represents the Smart Meter.

The ESP32 publishes IoT telemetry through MQTT to the Edge-AI gateway.

The Edge-AI gateway receives the MQTT data and converts the telemetry into the feature format required by the Random Forest model.

The Random Forest model classifies the simulated traffic as NORMAL or ATTACK.

Detected attacks are stored in the intrusion log and displayed on the dashboard.
