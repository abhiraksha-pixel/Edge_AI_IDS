3. Random Forest

The trained classifier analyzes the simulated traffic features.

4. Detection Result

The model produces a NORMAL or ATTACK classification.

NORMAL Classification

Normal traffic condition

The model classifies traffic as NORMAL when the simulated network features correspond to the normal traffic patterns used during training.

The result is recorded in the traffic log for subsequent analysis.

ATTACK Classification

Simulated anomalous traffic condition

The model classifies traffic as ATTACK when the simulated network features correspond to the attack patterns used during training.

Detected attack events are written to the intrusion log and displayed in the dashboard.

Model Evaluation

Interpretation of model performance

The Random Forest model was trained using the project's simulated IoT traffic dataset.

The training dataset contains simulated NORMAL and ATTACK traffic generated using predefined feature ranges.

Performance metrics such as accuracy, precision, recall and F1-score should be reported from the recorded test-set evaluation rather than inferred from the live prediction confidence shown by the dashboard.

The current dashboard displays the model configuration and deployed model information. It does not treat prediction confidence as model accuracy.

Important Project Note

Scope of the current model implementation

This project uses simulated IoT traffic for demonstration and experimentation.

The Wokwi ESP32 telemetry is converted into the network-feature format expected by the trained Random Forest model.

This conversion is a simulation adapter. The current implementation does not perform direct packet capture or deep packet inspection of a real IoT network.

Therefore, model results shown by this project should be interpreted within the scope of the simulated dataset and experimental environment.
