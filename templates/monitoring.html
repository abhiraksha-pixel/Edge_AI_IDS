Monitoring Process

How data moves through the Edge-AI intrusion detection system

The Wokwi environment simulates an ESP32 IoT gateway containing five IoT components: Smart Light, Smart Thermostat, Smart Camera, Smart Lock and Smart Meter.

The ESP32 generates simulated IoT telemetry and publishes the data using the MQTT protocol.

The Python Edge-AI gateway subscribes to the MQTT topic and receives the telemetry generated by the simulated ESP32.

The received telemetry is converted into the feature format expected by the trained Random Forest model.

The model classifies the simulated network condition as NORMAL or ATTACK.

When an attack is detected, the event is written to the intrusion log and displayed on the monitoring interface.
