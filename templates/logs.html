Intrusion Logging Pipeline

How detected attacks are recorded

1. IoT Telemetry

ESP32 publishes simulated telemetry through MQTT.

2. Edge-AI Analysis

Python receives the message and processes the data.

3. ML Classification

Random Forest classifies the simulated traffic.

4. Intrusion Log

Detected attack events are stored in the intrusion log.

Log Interpretation

Meaning of the recorded intrusion events

The events shown on this page represent simulated intrusion conditions generated by the project.

The ESP32 telemetry is transmitted through MQTT to the Python Edge-AI gateway, where the received information is converted into the feature format expected by the trained Random Forest model.

When the model classifies the simulated traffic as ATTACK, the event is written to the intrusion log.

The packet size, packet rate, connections and duration shown here are the network features used by the simulation and classification pipeline.

These logs represent a software simulation and should not be interpreted as measurements of attacks on a real IoT network.
